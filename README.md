# Impulso Pro — Projeto de Banco de Dados

Projeto acadêmico desenvolvido em grupo na disciplina de **Banco de Dados** 
(1º semestre, Ciência da Computação, UNICID — 2025).

## O que está aqui

Este repositório contém todos os artefatos formais da modelagem de dados do sistema 
Impulso Pro, uma plataforma de gestão de treinamentos para redes de restaurantes.

- **Minimundo** — Descrição narrativa do domínio do sistema
- **DER** — Diagrama Entidade-Relacionamento
- **MER** — Modelo Entidade-Relacionamento
- **Normalização** — Verificação e aplicação até a Terceira Forma Normal (3NF)
- **Script SQL** — Schema completo do banco de dados (`Impulso_Pro.sql`)
